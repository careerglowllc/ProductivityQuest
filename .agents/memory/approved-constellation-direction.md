name: Approved constellation direction
description: Confirmed visual target for future Life OS skill-tree work.
---

Use the full-screen, reference-driven constellation treatment for the Skills experience: muted periwinkle field, compact central nebula, radial colored hubs, fine luminous branches, sparse uppercase labels, and cinematic isolated branch views. Do not pull visual chrome from the rest of Life OS into this experience.

**Why:** The user explicitly confirmed this substantially different, reference-faithful direction as exactly the UI they want after rejecting an earlier version that looked too much like the existing application.

When visual fidelity and legacy functionality compete, preserve the approved composition, particle density, glow hierarchy, branch geometry, and motion first. Layer production functionality back in only where it does not flatten or obscure the experience.

**How to apply:** Preserve this visual grammar when extending skill domains, node content, transitions, or production behavior. Avoid dashboards, cards, editorial hero sections, and permanent inspector panels in the constellation view. Treat the standalone HTML as the visual and motion reference when changing the React page.

Light mode keeps every semantic skill hue identical to dark mode and inverts only the neutral atmosphere: a warm whitish field with charcoal/gray texture, particles, branches, nodes, labels, and controls. Use dark neutral hub interiors so the unchanged pastel skill colors retain accessible contrast.

**Why:** The user explicitly requested a light counterpart without recoloring the skill categories, while preserving the existing periwinkle treatment as the dark-mode version.

**How to apply:** Any future constellation styling must be checked in both `html.light` and `html.dark`, including the full Skills scene and dashboard mini-replica. Do not derive new light-mode variants of the semantic skill colors.
