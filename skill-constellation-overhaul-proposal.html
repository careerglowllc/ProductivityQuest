Skill tree / concept 02

Turn the constellation into a mastery map.

The current radial layout has a strong foundation. The sharper direction is to reduce visual clutter, create a clear center-to-branch hierarchy, and make every selection feel like opening a living capability—not just clicking an icon.

01 / Design direction

Sharper structure, warmer reward.

Keep the space-and-mastery metaphor, but replace the current equal-weight ring with a readable progression: identity at the center, disciplines in orbit, milestones on branches.

Jump to constellation
01

Make the hierarchy legible

The core is the user's overall mastery. Major skills become named orbit nodes. Milestones become smaller points on each branch.

02

Separate states with light

Gold means earned, blue means available, violet means selected, and dim lines mean locked or future progression.

03

Selection opens context

A selected skill should expand a compact detail surface with level, description, progress, and a single route to milestones.

Progressive disclosure

Don't force users to pan a large tree on a small screen. Keep the current skill anchored, with the full map one link away.

Tap feedback

Selected nodes should briefly expand, pulse, and update the title immediately. The user should never wonder whether their tap registered.

Persistent orientation

Keep the current skill name and level outside the map so context survives scrolling and zooming.

04 / Selection motion

Motion should explain state.

Use short, deliberate transitions instead of constant spectacle. Every animation answers a question: what changed, what is selected, and where can I go next?

Back to top
01

Hover / focus

Scale the node slightly, lift the glow, and reveal the discipline label. Keyboard focus gets the same visible treatment as pointer hover.

02

Selection

Pulse one outer ring, brighten connected paths, and raise the detail panel from the lower edge. Keep it under 300ms.

03

Completion

When a milestone completes, run one outward shimmer along its branch, then settle the node into the earned gold state.

Recommended next step

Build the constellation as a reusable interaction.

Keep the current skill and milestone data model. Replace the presentation layer with a responsive map, explicit node states, and a selected-skill detail surface.
